# Операторы в JavaScript и динамическая типизация

## 1. Арифметические операторы

Сложение:
`5 + 3 // 8`

Вычитание:
`5 - 3 // 2`

Умножение:
`5 * 3 // 15`

Деление:
`5 / 2 // 2.5`

Остаток от деления:
`5 % 2 // 1`

Возведение в степень:
`2 ** 3 // 8`

Инкремент:
`let x = 5; x++ // 6`

Декремент:
`let y = 5; y-- // 4`

## 2. Операторы присваивания

Присваивание:
`let a = 10;`

Сложение и присваивание:
`a += 5; // a = a + 5`

Вычитание и присваивание: `a -= 5; // a = a - 5`

Умножение и присваивание:
`a *= 5; // a = a * 5`

Деление и присваивание:
`a /= 5; // a = a / 5`

Остаток от деления и присваивание:
`a %= 3; // a = a % 3`

Возведение в степень и присваивание:
`a **= 2; // a = a ** 2`

## 3. Операторы сравнения

Равенство:
`5 == "5" // true`

Строгое равенство:
`5 === "5" // false`

Неравенство:
`5 != "5" // false`

Строгое неравенство:
`5 !== "5" // true`

Больше:
`5 > 3 // true`

Меньше:
`5 < 3 // false`

Больше или равно:
`5 >= 5 // true`

Меньше или равно:
`5 <= 3 // false`

## 4. Логические операторы

Логическое "И":
`(true && false) // false`

Логическое "ИЛИ":
`(true || false) // true`

Логическое "НЕ":
`!true // false`

Nullish coalescing (возвращает первый непустой операнд):
`null ?? "default" // "default"`

## 5. Побитовые операторы

Побитовое "И":
`5 & 1 // 1`

Побитовое "ИЛИ":
`5 | 1 // 5`

Побитовое "XOR" (исключающее ИЛИ):
`5 ^ 1 // 4`

Оператор XOR (исключающее ИЛИ) сравнивает соответствующие биты двух чисел и возвращает 1, если только один из битов равен 1.

Побитовое "НЕ":
`~5 // -6`

Оператор НЕ инвертирует все биты числа и возвращает дополнительный код, что соответствует `-(число + 1)`.

Сдвиг влево:
`5 << 1 // 10`

Сдвигает биты числа влево, заполняя нулями справа. Умножает число на 2 в указанной степени.

Сдвиг вправо:
`5 >> 1 // 2`

Сдвигает биты числа вправо, сохраняя знак числа. Делит число на 2 в указанной степени.

Беззнаковый сдвиг вправо:
`5 >>> 1 // 2`

Сдвигает биты числа вправо, заполняя нулями слева. Работает как обычный сдвиг вправо, но всегда возвращает положительное число.

## 6. Тернарный оператор

Тернарный оператор (`?:`) позволяет записывать условные выражения в одной строке. Если условие истинно, возвращается первое значение, иначе второе.

```js
let result = (5 > 3) ? "Yes" : "No"; // "Yes"
```

## 7. Операторы typeof и instanceof

typeof Определяет тип переменной:
`typeof 5 // "number"`

instanceof Проверяет, принадлежит ли объект классу:
`new Date() instanceof Date // true`

## 8. Оператор запятая ,

Оператор запятая выполняет несколько выражений и возвращает результат последнего.

```js
let x = (1, 2, 3, 4); // x = 4
```

## 9. Оператор delete

Оператор `delete` удаляет свойство объекта.

```js
let obj = { a: 1, b: 2 };
delete obj.a; // obj теперь { b: 2 }
```

## 10. Оператор in

Оператор `in` проверяет, существует ли свойство в объекте.

```js
"a" in { a: 1, b: 2 }; // true
```

## 11. Оператор void

Оператор `void` используется для получения `undefined`, независимо от переданного выражения.

```js
void 0; // undefined
```

## 12. Оператор new

Оператор `new` используется для создания экземпляра объекта, основанного на конструкторе.

```js
let date = new Date();
```

## 13. Оператор super

Оператор `super` вызывает конструктор родительского класса внутри дочернего класса.

```js
class Parent {
  constructor() { console.log("Parent"); }
}

class Child extends Parent {
  constructor() {
    super();
    console.log("Child");
  }
}

new Child(); // "Parent" "Child"
```

## 14. Оператор this

Оператор `this` ссылается на текущий контекст выполнения, который зависит от способа вызова функции.

```js
const obj = {
  name: "JS",
  show() { console.log(this.name); }
};

obj.show(); // "JS"
```

## 15. Динамическая типизация данных

JavaScript является языком с динамической типизацией. Это означает, что переменная может содержать значения разных типов в разные моменты выполнения программы без явного преобразования типов.

Пример использования динамической типизации:
```js
let variable = "Hello, World!"; // Переменная содержит строку
console.log(typeof variable); // "string"

variable = 42; // Теперь переменная содержит число
console.log(typeof variable); // "number"

variable = true; // Теперь переменная содержит булево значение
console.log(typeof variable); // "boolean"
```

Динамическая типизация позволяет писать более гибкий код, но также требует осторожности при работе с переменными, чтобы избежать неожиданных ошибок.
